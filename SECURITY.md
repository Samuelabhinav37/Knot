# Security Policy

Report vulnerabilities using [GitHub private vulnerability reporting](https://github.com/Samuelabhinav37/Knot/security/advisories/new). Do not publish secrets or exploitation details in an issue.

Useful reports include authentication or authorization problems, exposed Firebase data, App Check bypasses, insecure local storage, exported Android components, WebView issues, and release-signing weaknesses.

Provide the app version or commit, Android version, device or emulator, reproduction steps, and impact. Test only against accounts, devices, and Firebase projects you control.

Security support currently applies to the default branch because no production release channel has been declared.
